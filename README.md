# KLA Hackathon Submission — Trial 18 Image Restoration

This project implements a custom image-restoration model for restoring noisy grayscale semiconductor images. The solution is built around a lightweight edge-aware ConvNeXt-V2 style restoration network and is tailored to process `.npy` image inputs and save restored PNG outputs.

## Project goal
The model is designed to denoise and recover clean image content from noisy inputs using:
- edge-aware feature extraction,
- residual ConvNeXt-V2 blocks,
- normalization based on dataset statistics,
- a combined restoration loss that balances pixel fidelity and edge preservation.

## Folder structure
- `train.py` — training pipeline, dataset loader, model architecture, and loss function
- `evaluate.py` — inference script for restoring `.npy` images and saving PNG outputs
- `train_metrics.py` — dataset-level evaluation using PSNR and SSIM
- `requirements.txt` — Python dependencies
- `trial_18_model.pth` — trained checkpoint
- `restored_test_outputs/` — sample restored outputs generated by the evaluator

## Model design
The architecture is implemented in `train.py` and `evaluate.py` and follows a residual encoder-decoder structure with the following components:

- `LaplacianEdgeExtractor` — computes edge maps from the noisy input
- `ConvNeXtV2Block` — depthwise convolution + layer normalization + GELU + GRN-based channel attention
- `RepPhyDAS_ConvNeXt` — encoder-decoder restoration network with skip connections
- `CombinedRestorationLoss` — combines Charbonnier loss with an edge-aware loss

This design helps preserve fine edges while reconstructing the clean target image.

## Data normalization
The model uses dataset statistics loaded from `dataset_statistics.json` during training:
- `a = a_p0_1`
- `b = b_p99_9`

These values normalize the input and target arrays before training, and the same values are restored during inference. This keeps the model input in a consistent numeric range while preserving the original dynamic range when converting outputs back to image form.

## Training flow
The training script:
1. loads the dataset from `./dataset/train/**/NoisyLR/*.npy`,
2. maps each noisy sample to its corresponding GT image,
3. normalizes inputs with dataset statistics,
4. trains the model with a custom combined loss,
5. saves the best checkpoint as `trial_18_model.pth`.

The model is trained using:
- `AdamW`
- cosine learning-rate decay
- gradient clipping
- mixed precision on CUDA-enabled systems

## Evaluation flow
The evaluation script accepts:
- an input directory containing `.npy` files,
- an output directory for saved restored PNGs,
- an optional model path.

It loads the checkpoint, restores each image, and saves outputs as grayscale PNGs named like:
- `000000_restored.png`
- `000001_restored.png`

The script also reports average inference latency in milliseconds.

## Metrics workflow
`train_metrics.py` is used to compute PSNR and SSIM against the training ground truth. It:
- iterates through the noisy training samples,
- runs inference with the saved model,
- loads matching GT frames,
- calculates quality measures,
- prints aggregate results for the dataset.

- `torch`

- `matplotlib`
- `scikit-image`
- `Pillow`

## Quick start
### 1) Train the model
```bash
python train.py
```

### 2) Run evaluation on a folder of noisy images
```bash
python evaluate.py --input_dir D:\path\to\input\npy --output_dir D:\path\to\output\pngs --model D:\KLA_Hackathon_Submission\trial_18_model.pth
```

### 3) Compute dataset metrics
Update the dataset paths at the top of `train_metrics.py` to match your local environment, then run:

```bash
python train_metrics.py
```

## Notes
- The scripts currently contain Windows-style absolute paths in the metric evaluation workflow. These should be adapted to your local machine or converted to configuration-based paths.
- The repo is built for grayscale restoration and expects `.npy` arrays with image-like dimensions.
- The model checkpoint stores normalization parameters `a` and `b`, which are required during inference.

## Summary
This repository demonstrates a practical, research-style image restoration pipeline for a KLA challenge setting, combining edge-aware CNN design, residual restoration blocks, and robust evaluation through PSNR/SSIM. It is well-suited for further experimentation with dataset tuning, architectural refinements, and larger training runs.
